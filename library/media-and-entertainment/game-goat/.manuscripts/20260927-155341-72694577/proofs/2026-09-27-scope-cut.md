# game-goat scope cut — 2026-09-27

User decision: game-goat is a **lookup-and-recommend** CLI, consumed primarily by **agents over the CLI**. The local backlog is dropped.

## Surface after the cut

Hand-authored commands kept: `games search`, `games get` (title resolver), `ratings`, `retention`, `series`, `similar`, `discover`, `games popular`, `games top-rated`, `games upcoming`. Generated endpoint mirrors and the standard press layer (sync/search/export/analytics/doctor/auth/which/agent-context/learning loop/MCP) unchanged.

Removed: `backlog` (+ `audit`), `queue`, `finishline`, `radar`, `tonight`, `moods`, `suggested`, `trending`, `versus`, `studio`; `internal/store/game_backlog.go` and its migration. ~4.8k lines deleted. Existing `data.db` keeps an orphaned `game_backlog` table (harmless, unused).

## `similar` absorbs `suggested`

Tiered free-tier join, each row tagged `tier` + `reason`, `meta.tiers` lists contributing tiers:
1. **studio** — seed's credited developers, capped at half the list; seed's own DLC/editions (`/games/{id}/additions`), soundtracks, and bundles excluded; confidence floor (>=20 ratings when any row clears it).
2. **mechanics** — defining gameplay tag via tag-neighborhood co-occurrence (unchanged algorithm), confidence-floored.
3. **genre** — shared-genre join only when short; thin seeds (no tags, no studio) hide single-broad-genre rows (F-U16 rule).
The business-tier `/suggested` probe was dropped (always 401 on free keys).

Known limitations (logged, not tuned in this pass): RAWG credits porters/publishers as developers, so the studio tier can pull unrelated catalogs (DOOM Eternal -> Bethesda's Elder Scrolls; reason string now lists all credited devs honestly); broad-ish vocabulary tags (`sandbox`, `open world`) can win the mechanics cluster (Stardew Valley, Halo -> open-world canon). A vocab tweak (drop sandbox, add fps) was probed and reverted — it moved Stardew/Terraria no closer.
